# Growth ORNIA

Client acquisition and automation landing page for ORNIA Group LLC.

## Run locally

Serve this folder with any static web server, for example `python3 -m http.server 8080`, then open http://localhost:8080.

## Deploy

The homepage is `index.html` at the repository root. No framework or build command is needed. On Vercel, select Other as the framework, leave the build command empty, and use the repository root as the output directory. GitHub Pages can serve the main branch from the root folder.

## Features

- Responsive navy design with the supplied background video
- Interactive acquisition process and FAQ sections
- Reduced-motion support and video pause control
- Transparent logo downloads in assets/logos

## Contact form

The form opens an email draft to admin@orniagroup.com. It does not yet submit directly to HighLevel or another CRM. The website describes ORNIA's services; it is not the CRM application itself.

## Media

Background footage supplied by the owner as My Movie 3.MOV, converted to a muted 1280×720 MP4. Inter and Instrument Serif are loaded from Google Fonts.
